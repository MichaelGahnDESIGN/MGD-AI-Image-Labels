# Release 0.6.2

## Korrektur des GitHub-Updaters

Dieses Release behebt einen Cache-Fall des eingebauten GitHub-Updaters. Wenn
WordPress kurz vor einem neuen Release geprüft hatte, enthielt der lokale
Release-Cache noch exakt die installierte Version. Diese veraltete Information
verhinderte bis zum Ablauf der Cachezeit, dass WordPress den neuen Release
erkannte.

Ab Version 0.6.2 wird ein Cache nur verwendet, wenn er bereits eine nachweislich
neuere Version enthält. Ein Cache mit derselben oder einer älteren Version führt
beim nächsten WordPress-Update-Check zu einer frischen, sicheren GitHub-Abfrage.

## Einmalige Installation

Die bereits installierte Version 0.6.0 enthält die alte Cache-Logik. Daher muss
Version 0.6.2 einmalig über **Plugins → Installieren → Plugin hochladen** als
ZIP installiert werden. WordPress aktualisiert dabei die vorhandene Erweiterung;
Kennzeichnungsdaten und Einstellungen bleiben erhalten. Danach funktionieren
weitere Updates wieder über den GitHub-Updater.
