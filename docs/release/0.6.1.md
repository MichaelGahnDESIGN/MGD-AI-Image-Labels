# Release 0.6.1

## Wichtigste Korrektur

Dieses Patch-Release behebt die Speicherung im Medienfenster von Divi 5.
Divi 5 betreibt die Builder-Oberfläche in einem eigenen Laufzeitfenster. Dort
war der Speichern-Button zwar sichtbar, sein Browser-Handler wurde jedoch nicht
geladen. Version 0.6.1 liefert den lokalen Handler bewusst auch für beide
Divi-Builder-Anfragen aus.

Der Handler ist außerdem unabhängig von jQuery. Er liest die drei Werte nur
aus dem aktuell sichtbaren Anhang-Dialog und sendet sie mit WordPress-Nonce und
Berechtigungsprüfung an die bestehende AJAX-Schnittstelle.

## Installation und Prüfung

1. Vor dem Update ein geprüftes Backup erstellen, zum Beispiel mit UpdraftPlus.
2. Das angebotene Update auf **0.6.1** installieren.
3. In Divi 5 ein Bild aus der Mediathek wählen, einen Status, eine Position und
   eine Glas-Variante setzen und **Kennzeichnung speichern** wählen.
4. Zu einem anderen Bild wechseln und zum ersten Bild zurückkehren. Alle drei
   Werte müssen unverändert angezeigt werden.
5. Die Seite speichern, Caches leeren und die Ausgabe im Frontend prüfen.

## Paketgrenzen

Das Release-ZIP enthält ausschließlich die für den Betrieb nötigen Plugin-Dateien.
Es enthält keine Zugangsdaten, Backups, Datenbankdaten, Tests, Worktrees oder
lokale Projektdateien.
