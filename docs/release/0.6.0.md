# Release 0.6.0

## Inhalt

Dieses Release bündelt die sichere Verwaltung und Ausgabe von KI-Bildkennzeichnungen für WordPress und Divi 5:

- zuverlässiges Speichern im sichtbaren Divi-5-Medienfenster,
- globale Darstellungsstandards unter **Medien → KI-Bildkennzeichnung**,
- Hintergrundbild-Labels per `[mgd_ai_label]`,
- lokal gepflegte AI-Philosophie per `[mgd_ai_philosophy]`,
- eine absichtlich zurückhaltende Seitenerstellung mit sicherer Footer-Regel,
- lokale WordPress-Plugin-Präsentation und Detailansicht.

## Installation

1. Vor dem Update ein geprüftes Backup der Website erstellen, zum Beispiel mit UpdraftPlus.
2. Die Datei `mgd-ai-image-labels-0.6.0.zip` in WordPress über **Plugins → Installieren → Plugin hochladen** installieren oder das angebotene Update verwenden.
3. Nach der Aktivierung unter **Medien → KI-Bildkennzeichnung** globale Standards prüfen.
4. Im Divi-5-Medienfenster eine Kennzeichnung speichern, den Anhang wechseln und erneut öffnen. Die drei Bildwerte müssen erhalten bleiben.
5. Seiten- und CDN-Caches leeren und das Frontend an einem gekennzeichneten Bild kontrollieren.

## Paketgrenzen

Das Release-ZIP enthält ausschließlich den Plugin-Ordner `mgd-ai-image-labels` mit den benötigten PHP-, CSS-, JavaScript-, Branding- und öffentlichen Dokumentationsdateien. Es enthält ausdrücklich keine Worktrees, Tests, lokalen Visualisierungen, Zugangsdaten, Datenbankauszüge, Backups oder bereits vorhandene ZIP-Archive.
