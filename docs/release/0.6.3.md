# Release 0.6.3

## Korrektur der dauerhaften Medienspeicherung

Dieses Release behebt die Ursache dafür, dass die Mediathek trotz positiver
Speichermeldung später wieder Standardwerte zeigte. WordPress kann zusätzlich
zur bewussten Kennzeichnungsaktion eine allgemeine Anhangsänderung auslösen.
Diese Anfrage enthält nicht immer die drei Plugin-Felder. Die bisherige
Behandlung interpretierte fehlende Werte fälschlich als Standardwerte und
überschrieb damit die Kennzeichnung.

Ab 0.6.3 werden ausschließlich tatsächlich übermittelte KI-Felder geschrieben.
Eine normale WordPress-Medienänderung ohne diese Felder lässt bestehende
Kennzeichnung, Position und Glas-Variante unverändert.

## Prüfung nach dem Update

1. In der Mediathek ein Bild öffnen.
2. Status, Position und Glas-Variante wählen und **Kennzeichnung speichern**.
3. Einen anderen Anhang öffnen und wieder zum ersten zurückkehren – alle drei
   Werte müssen erhalten bleiben.
4. Die Mediathek neu laden und denselben Anhang erneut öffnen.
5. Den gleichen Ablauf im Divi-5-Bilderdialog wiederholen.
